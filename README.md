# Customer Support Data - Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on a customer support dataset to uncover patterns, trends, and insights related to customer service operations.

The analysis includes data cleaning, visualization, and statistical exploration to better understand customer interactions and support performance.

---

## 🎯 Objectives

- Understand the structure of the dataset
- Clean missing and duplicate values
- Perform univariate and bivariate analysis
- Visualize important features
- Discover business insights from customer support data

---

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📂 Dataset

Customer Support Dataset

The dataset contains customer support information such as:
- Customer Details
- Support Categories
- Response Time
- Resolution Status
- Ratings
- Other customer service attributes

---

## 📊 Analysis Performed

- Data Loading
- Data Cleaning
- Missing Value Analysis
- Duplicate Value Removal
- Descriptive Statistics
- Correlation Analysis
- Distribution Plots
- Count Plots
- Box Plots
- Heatmaps

---

## 📈 Key Insights

- Identified trends in customer support requests.
- Analyzed customer satisfaction ratings.
- Observed response time distribution.
- Detected feature relationships using correlation analysis.
- Generated visual reports for better decision making.
